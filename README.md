# GraphIS — визуальный редактор графов и алгоритмов поиска пути

**GraphIS** (Graph Information System) — кроссплатформенное десктопное приложение для визуального построения графов
и пошаговой демонстрации алгоритмов поиска пути. Проект разработан в рамках выпускной квалификационной работы
и предназначен для образовательных целей: школ, колледжей и университетов.

Граф строится мышью, любой из девяти алгоритмов проходится по шагам прямо на холсте, а вкладка «Анализ»
показывает матрицу смежности и сравнивает алгоритмы между собой.

## Возможности

### Редактор графов
- Добавление вершины двойным кликом по холсту или кнопкой «Вершина»
- Создание ребра — правой кнопкой мыши по двум вершинам
- Перемещение вершин перетаскиванием, изменение масштаба (Ctrl + колёсико)
- Четыре типа графа: ориентированный / неориентированный, взвешенный / невзвешенный
- Веса рёбер, названия вершин и рёбер — в панели свойств
- Отмена и повтор действий (Ctrl+Z / Ctrl+Y)
- Автосохранение каждого изменения

### Алгоритмы поиска пути
Девять алгоритмов с пошаговой визуализацией. На холсте подсвечиваются текущая вершина, очередь (стек, открытое
множество), обработанные вершины, проверяемое ребро и найденный путь; в боковой панели — описание алгоритма,
номер шага и таблица меток вершин.

| Алгоритм | Что минимизирует | Сложность | Кратчайший путь |
|---|---|---|---|
| Алгоритм Дейкстры | суммарный вес | O((V + E) log V) | да |
| A* (эвристика — расстояние до цели) | суммарный вес | O((V + E) log V) | да |
| Алгоритм Беллмана — Форда | суммарный вес, допускает отрицательные веса, находит отрицательные циклы | O(V · E) | да |
| Алгоритм Флойда — Уоршелла | суммарный вес между всеми парами вершин | O(V³) | да |
| Поиск в ширину (BFS) | число рёбер | O(V + E) | да |
| Двунаправленный поиск | число рёбер | O(V + E) | да |
| Итеративное углубление (IDDFS) | число рёбер | O(V + E) на каждую глубину | да |
| Поиск в глубину (DFS) | — | O(V + E) | нет |
| Жадный поиск (Best-First) | — | O((V + E) log V) | нет |

### Анализ
- **Граф в цифрах:** число вершин и рёбер, плотность, средняя степень
- **Матрица смежности** в виде таблицы: рёбра подсвечены, обновляется при любом изменении графа
- **Сравнение алгоритмов:** все девять запускаются между выбранными вершинами; приложение формулирует выводы
  и строит диаграммы числа шагов и обработанных вершин, показывает вес и длину найденных путей
- **Характеристики алгоритмов** и график теоретической сложности

### Оформление
- Светлая, тёмная тема или «как в системе»; восемь акцентных цветов
- Настройка размера и шрифта вершин, толщины и шрифта рёбер, пунктирных рёбер
- Ширину боковой панели можно менять, перетаскивая её границу

## Архитектура

Приложение построено по паттерну **MVVM**:

- **View** — окна Avalonia (XAML). Холст графа рисуется привязками к данным, в code-behind остаются только
  события мыши и прокрутка.
- **ViewModel** — состояние экранов, команды, история отмены, анализ. Не работает напрямую с файлами и окнами.
- **Сервисы** — хранилище графов (`IGraphRepository`), открытие окон (`IWindowService`), тема (`IThemeService`),
  настройки (`ISettingsStore`). Подключаются через DI и подменяются в тестах.
- **Алгоритмы** — отдельные классы без зависимости от интерфейса. Все алгоритмы поиска пути реализуют общий
  интерфейс `IPathFindingAlgorithm`: получают «снимок» графа и возвращают последовательность шагов одного формата,
  поэтому редактор показывает любой из них одинаково, а новый алгоритм добавляется одним классом.

```
src/Thesis/
├── Algorithms/          алгоритмы поиска пути, матрица смежности, анализ сложности
│   └── PathFinding/     BFS, DFS, A*, Беллман — Форд, Флойд — Уоршелл и другие
├── Controls/            собственные элементы: иконки, график сложности
├── Models/              граф, настройки
├── Services/            хранилище, окна, тема, настройки
├── Themes/              цвета светлой и тёмной темы, стили, иконки
├── ViewModels/          Editor, Welcome, Settings, Dialogs
└── Views/               Editor, Welcome, Settings, Dialogs
tests/Thesis.Tests/      модульные тесты (та же структура)
```

## Установка и запуск

### Готовая сборка

1. Скачайте последнюю версию `GraphIS.exe` из раздела [Releases](https://github.com/prop1l/Thesis/releases)
2. Поместите файл в любую папку
3. Запустите `GraphIS.exe` двойным кликом

### Из исходного кода

Нужен [.NET SDK 10](https://dotnet.microsoft.com/download).

```bash
git clone https://github.com/prop1l/Thesis
cd Thesis
dotnet run --project src/Thesis
```

### Тесты

```bash
dotnet test
```

124 модульных теста: общие проверки для каждого алгоритма (корректность пути, учёт направления рёбер,
отсутствие пути), особенности отдельных алгоритмов, редактор, отмена и повтор, анализ, хранение, главный экран
и настройки.

## Где хранятся данные

Графы и настройки сохраняются в папке пользователя: `%APPDATA%\GraphIS` в Windows
(`~/.config/GraphIS` в Linux и macOS):

- `graphs.json` — список графов
- `<название графа>.json` — данные графа: вершины, рёбра, тип, оформление
- `settings.json` — тема и акцентный цвет
