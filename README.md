# GraphIS — визуальный редактор графов и алгоритмов

**GraphIS** (Graph Information System) — это кроссплатформенное десктопное приложение для визуального построения графов и демонстрации работы алгоритмов поиска путей. Проект разработан в рамках выпускной квалификационной работы и предназначен для использования в образовательных целях (школы, колледжи, университеты).

##  Основные возможности

- **Визуальное создание и редактирование графов**
  - Добавление/удаление вершин двойным кликом или кнопкой
  - Создание/удаление рёбер (правая кнопка мыши)
  - Задание весов рёбер
  - Перемещение вершин перетаскиванием

- **Алгоритмы с пошаговой визуализацией**
  - Алгоритм Дейкстры (кратчайший путь во взвешенном графе)
  - Подсветка текущих обрабатываемых вершин и рёбер
  - Отображение найденного пути и его суммарного веса

- **Настройка внешнего вида**
  - Светлая и тёмная тема оформления
  - Выбор акцентного цвета
  - Настройка размеров и цветов вершин
  - Настройка толщины и цвета рёбер

- **Сохранение и загрузка**
  - Автоматическое сохранение всех изменений
  - Загрузка ранее созданных графов из списка
  - Хранение данных в формате JSON

##  Технологии

| Технология | Назначение |
|------------|------------|
| C# / .NET 8 | Язык и платформа разработки |
| Avalonia UI | Кроссплатформенный фреймворк для GUI |
| CommunityToolkit.Mvvm | Реализация паттерна MVVM |
| System.Text.Json | Сериализация данных в JSON |

## Установка и запуск
### Запуск приложения (без установки)

1. Скачайте последнюю версию `GraphIS.exe` из раздела [Releases](https://github.com/prop1l/GraphIS/releases)
2. Поместите файл в любую папку на вашем компьютере
3. Запустите `GraphIS.exe` двойным кликом

### Запуск из исходного кода

```bash
# Клонирование репозитория
git clone https://github.com/ваш-аккаунт/GraphIS.git

# Переход в папку проекта
cd GraphIS

# Восстановление зависимостей
dotnet restore

# Запуск приложения
dotnet run --project Thesis
